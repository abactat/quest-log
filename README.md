# quest-log

A live, game-style quest log for Claude Code `/goal` runs and plans: a ranger hero who levels up as goals are met, a guardian monster for each quest, a d20 that rolls at every goal check, and a plain-English log of what Claude did. It only watches, so it costs no tokens.

```
claude plugin marketplace add abactat/quest-log
claude plugin install quest-log@quest-mods --scope user
```

Then `/reload-plugins` in any open chat, and `/quest` to open the pane.

Details, credits and licences: [quest-log/README.md](quest-log/README.md).
